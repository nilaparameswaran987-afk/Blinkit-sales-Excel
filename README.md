# Blinkit Sales Dashboard | Excel

An interactive Excel dashboard created to analyze Blinkit sales, payment methods, city-wise sales, categories, profit, and daily orders.

## Dashboard Preview

![Blinkit Sales Dashboard](BLINKIT%20EXCEL.png)

## Dashboard Highlights

- Payment mode split analysis
- City-wise sales comparison
- Top 5 product categories
- Profit by subcategory
- Top 5 cities by sales
- Daily order trend
- Interactive filters for city, profit, and customer rating

## Key Insights

- Top city: Pune
- Sales by Bangalore, Chennai, Delhi, Hyderabad, Kolkata, Mumbai, and Pune
- Payment modes: Cash on Delivery, Credit Card, Debit Card, UPI, and Wallet
- Category analysis: Fruits & Vegetables, Dairy & Bakery, Frozen Foods, Household Items, and Personal Care
